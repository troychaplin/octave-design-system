# Container

A page-level content container that controls width, background, and vertical rhythm. Nests inside `Main` and wraps layout components like `Column`, `Article`, and `Aside`. Three max-width presets align with the WordPress block editor's alignment system.

## When to use

Use `Container` to group related content into a distinct visual band — a card grid, an article body, a call-to-action strip. Stack multiple `Container` components inside `Main` to build alternating white and grey content rows. Use `maxWidth="alignfull"` with `bgType="grey"` for full-bleed accent sections. Add `contentWidth` when you want the section background to span one width while the children are constrained to a narrower readable column.

## Import

```tsx
import { Container } from '@troychaplin/octave-design-system';
```

## Basic usage

```tsx
// Default — content width, white background
<Main>
  <Container>
    <Column cols="3">...</Column>
  </Container>
</Main>

// Grey background
<Main>
  <Container bgType="grey">
    <Column cols="2">...</Column>
  </Container>
</Main>

// Black background (automatically inverts text to white)
<Main>
  <Container bgType="black">
    <Column cols="2">...</Column>
  </Container>
</Main>

// Light gradient background
<Main>
  <Container bgType="light-gradient">
    <Column cols="2">...</Column>
  </Container>
</Main>

// Full-bleed grey band
<Main>
  <Container maxWidth="alignfull" bgType="grey">
    <Column cols="3">...</Column>
  </Container>
</Main>

// Full-bleed grey band with content constrained to 1024px
<Main>
  <Container maxWidth="alignfull" bgType="grey" contentWidth="aligncontent">
    <Column cols="2">...</Column>
  </Container>
</Main>

// Full-bleed grey band with content constrained to 1280px
<Main>
  <Container maxWidth="alignfull" bgType="grey" contentWidth="alignwide">
    <Column cols="2">...</Column>
  </Container>
</Main>
```

## Max-width presets

| `maxWidth`       | Token                           | Description                                    |
| ---------------- | ------------------------------- | ---------------------------------------------- |
| `"aligncontent"` | `--octave--layout-content-size` | Default — standard readable content width      |
| `"alignwide"`    | `--octave--layout-wide-size`    | Wider — for card grids and media-rich sections |
| `"alignfull"`    | `--octave--layout-full-size`    | Full viewport width — hero and accent bands    |

These names and tokens mirror the WordPress block editor's alignment system so that React templates and WordPress block themes share the same layout vocabulary.

## The `as` prop

By default `Container` renders a `<section>` element. Pass `as="div"` when a section landmark is semantically inappropriate — for example, a purely decorative spacer row or a wrapper that forms part of a larger landmark region.

## The `contentWidth` prop

When set, `contentWidth` wraps all children in a `octave-section__content` div independently constrained within the outer layout:

| Value            | Inner content width                                   |
| ---------------- | ----------------------------------------------------- |
| `"aligncontent"` | 1024px — standard readable content width              |
| `"alignwide"`    | 1280px — wider, for card grids and media-rich layouts |
| `"alignfull"`    | Full viewport width                                   |

Omitting `contentWidth` keeps the existing behaviour: children are direct children of the root and the root's `is-layout-constrained` applies.

## CSS classes

| Class                            | When applied                                          |
| -------------------------------- | ----------------------------------------------------- |
| `octave-section`                 | Always                                                |
| `octave-section--grey`           | `bgType="grey"`                                       |
| `octave-section--black`          | `bgType="black"`                                      |
| `octave-section--light-gradient` | `bgType="light-gradient"`                             |
| `aligncontent`                   | `maxWidth="aligncontent"` (default)                   |
| `alignwide`                      | `maxWidth="alignwide"`                                |
| `alignfull`                      | `maxWidth="alignfull"`                                |
| `has-global-padding`             | When `bgType` is set — horizontal gutter              |
| `is-layout-constrained`          | Always — constrains children to content / wide widths |

## Design tokens

| Token                                   | Used for                                        |
| --------------------------------------- | ----------------------------------------------- |
| `--octave--color-grey-pale`             | Grey section background                         |
| `--octave--color-black`                 | Black section background                        |
| `--octave--gradient-white-to-pale-grey` | Light gradient section background               |
| `--octave--spacing-large`               | Internal padding on styled sections             |
| `--octave--radius-md`                   | Border radius on non-full-width styled sections |
| `--octave--layout-content-size`         | `aligncontent` max-width                        |
| `--octave--layout-wide-size`            | `alignwide` max-width                           |
| `--octave--layout-full-size`            | `alignfull` max-width (100%)                    |

## Accessibility

- `<section>` is a landmark element when it has an accessible name — add `aria-label` or `aria-labelledby` via the standard HTML prop when the section's purpose should be surfaced to screen reader navigation.
- Without an accessible name, `<section>` is not exposed as a landmark, which is acceptable for generic layout sections. Use `as="div"` if you actively want to suppress any landmark semantics.
- When stacking many sections on a single page, ensure each meaningful `<section>` landmark has a distinct label so screen reader users can distinguish between them in landmark navigation.
