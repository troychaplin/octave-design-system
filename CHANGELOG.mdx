# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Prefix the change with one of these keywords:

- _Added_: for new features.`
- _Breaking_: for higher visibility of breaking changes
- _Changed_: for changes in existing functionality.
- _Deprecated_: for soon-to-be removed features.
- _Removed_: for now removed features.
- _Fixed_: for any bug fixes.
- _Security_: in case of vulnerabilities.

## [Unreleased]

_Added_ `FlexGroup` layout component — a flex container mirroring the flex half of the
WordPress Group block, with `direction`, `wrap`, `justify`, `align`, `gap`, `padding`,
`margin` and `maxWidth` props. Unlike the block it uses CSS axis semantics (`justify` is
always `justify-content`) rather than swapping the axes in a vertical layout.

_Added_ `spacingClasses`, `flexJustifyClasses` and `flexAlignClasses` to `propClasses`.

_Changed_ `Section` is renamed `Container`.

_Added_ `Container` spreads remaining props onto its root element, so `style`, `id`, `aria-*`,
`data-*` and event handlers pass through.

_Breaking_ `Button` `color` variants are renamed to semantic names that map onto the palette:
`primary` (was `red`, still the default), `neutral` (was `grey`), `dark` (was `dark-grey`) and
`light` (was `white`), plus a new `secondary`. `blue` and `black` are removed.

_Breaking_ `Button`'s label prop is renamed from `title` to a required `text`, matching `Badge`.
The native `title` attribute now passes through as a tooltip. `ariaLabel` and the
`ButtonTitleProps` / `ButtonNoTitleProps` types are removed — pass `aria-label` instead.

_Breaking_ `Button` `isDisabled` is replaced by the native `disabled` attribute.

_Added_ `Button` renders a link through `LinkProvider` when `href` is provided. TypeScript rejects
the button-only `type` and `disabled` props on a link.

_Fixed_ `Button` appends a consumer's `className` instead of replacing its own classes.

_Removed_ The unused `octave-button--center` class.

_Breaking_ `Badge` `color` variants are renamed to semantic names: `neutral` (was `grey`, still the
default), `light` (was `white`), `info`, `success`, `warning` and `error` (were `blue`, `green`,
`yellow` and `red`), and `overlay-dark` / `overlay-light` (were `black80` / `white80`). `purple`
and `teal` are removed.

_Fixed_ `Button`, `Badge`, `Figure`, `Main` and the stylebook referenced color tokens that no
longer exist, so backgrounds rendered transparent and text fell back to inherited colors. They now
use the `accent-*` and `neutral-*` tokens, and `Main` link hover uses the base link hover color.

_Fixed_ Links use `accent-primary` instead of `success` green, meeting the WCAG AA 4.5:1 contrast
ratio on the page background.

_Fixed_ The `BadgeGroup` and `Button` docs pages no longer crash on `<Canvas>` blocks that
referenced stories that don't exist (`OnCard`, `WithIcon`, `IconOnly`), and the Button docs no
longer describe an `icon` prop. Dead links in the `Badge`, `FlexGroup` and `LinkProvider` docs are
fixed.

_Fixed_ The Source Serif 4 font stack is now quoted, so body copy and serif text render in Source
Serif 4 instead of falling back to system fonts. Browsers ignored the whole stack because a family
name without quotes can't contain a word that starts with a digit.

_Added_ `SiteHeader` `siteTitleAccent` prop wraps the matching part of `siteTitle` in
`octave-site-header__title-accent`, so that part can be styled on its own.

_Added_ `CodeBlock` component: renders a string of code in `<pre><code>` in JetBrains Mono, keeping
its line breaks and indentation, and scrolls sideways when a line is too long to fit. A `color` prop
takes the same `light`, `medium`, `dark` and `white` backgrounds as `Container`, with white text on
`medium` and `dark`. `hasBorder` adds a 1px border: `neutral-300` on the default, `light` and `white`
backgrounds, and the background's own color on `medium` and `dark`, so a bordered block stays the
same size whatever its color. `borderRadius` rounds the corners with the `none`, `sm`, `md`, `lg`,
`xl` and `full` radius tokens.

_Fixed_ `Container` `borderRadius="xl"` now rounds the corners. The value was accepted but had no
style rule, so the corners stayed square.
