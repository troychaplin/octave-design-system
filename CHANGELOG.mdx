# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Prefix the change with one of these keywords:

- _Added_: for new features.
- _Breaking_: for higher visibility of breaking changes
- _Changed_: for changes in existing functionality.
- _Deprecated_: for soon-to-be removed features.
- _Removed_: for now removed features.
- _Fixed_: for any bug fixes.
- _Security_: in case of vulnerabilities.

## [Unreleased]

_Added_ `SkipLink`, a link that stays hidden until it gets keyboard focus and then jumps past the
header to the page's main content. It targets `#main` by default.

_Changed_ `Main` renders with `id="main"` and `tabIndex={-1}` by default, so a skip link can move
focus into it. Pass `id` or `tabIndex` to override either.

_Breaking_ `Card` replaces its `padding` prop with `paddingInline` and `paddingBlock`, so the sides
and the top and bottom can be set separately. Both default to `large`, which matches the old
default. The `parlour-card--padding-{step}` classes are now `parlour-card--padding-inline-{step}`
and `parlour-card--padding-block-{step}`.

## [0.1.0] - 2026-10-04

The first release under the Parlour name. The project was formerly developed as "Octave Design
System" and published as `@troychaplin/octave-design-system`. It now ships as
`@troychaplin/parlour-ui`, and the version history starts again here. Code written against the old
package needs the new package name in its imports, `--parlour--` in place of the `--octave--`
custom properties, and `parlour-` in place of the `octave-` class names.

_Added_ A token pipeline. Colors, three font families with bundled font files, 16 fluid type
sizes, a 12-step spacing scale, shadows, radii and layout widths are defined once in
`c2b.config.json`, and `@troychaplin/component2block` generates them as `--parlour--*` custom
properties, SCSS variables and breakpoint mixins, base element styles, layout classes and the
`parlourTokens` JavaScript export.

_Added_ WordPress outputs in `dist/wordpress/`: `theme-parlour.json` with the tokens as
`theme.json` presets, `integrate.php` to load it as WordPress's default `theme.json` layer, and
`block-theme.css` and `hybrid-theme.css` for block and hybrid themes. Each component's CSS is also
published on its own, so a block can bundle only what it renders.

_Added_ Accessibility checks. Every Storybook story runs through axe at the `error` threshold, in
CI and on pre-push, so a violation fails the build.

_Added_ Components: Elements (`Button`, `ButtonGroup`), Content (`Card`, `CodeBlock`, `Figure`,
`Hero`, `HeroHeader`, `SectionHeader`), Layout (`Column`, `Container`, `FlexGroup`, `GridGroup`),
Template Parts (`Article`, `Aside`, `Body`, `InfoBar`, `Main`, `SiteHeader`) and Utilities
(`LinkProvider`). They ship as ES modules and CommonJS with TypeScript types, and work in Next.js
Server Components.
