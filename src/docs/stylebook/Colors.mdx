# Colors

Color tokens are defined in `c2b.config.json` and generate CSS custom properties
prefixed with `--octave--color-*`. Use these tokens for all color references to
maintain consistency across the design system.

## Usage

```css
.my-element {
    color: var(--octave--color-accent-primary);
    background: var(--octave--color-neutral-50);
}
```
