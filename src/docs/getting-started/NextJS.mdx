# Next.js usage

Using `@troychaplin/parlour-ui` in a Next.js app. Assumes you've completed [Installation](?path=/docs/overview-getting-started-installation--docs).

## App Router

### Server and Client Components

Parlour's components work in Server Components. `Button`, `SiteHeader` and `LinkProvider` use React context, so they're marked `'use client'` and render as Client Components; every other component renders on the server.

### Import styles and wire up Next.js Link

[`LinkProvider`](?path=/docs/components-utilities-linkprovider--docs) makes Parlour components that take an `href` route through Next.js's `Link`, with prefetching and client-side navigation. A Server Component can't pass a function such as `Link` to a Client Component, so put the provider in a client file:

```tsx
// app/providers.tsx
'use client';

import Link from 'next/link';
import { LinkProvider } from '@troychaplin/parlour-ui';

export function Providers({ children }: { children: React.ReactNode }) {
    return <LinkProvider component={Link}>{children}</LinkProvider>;
}
```

Then import the stylesheet and the providers in the root layout:

```tsx
// app/layout.tsx
import '@troychaplin/parlour-ui/styles.css';
import { Providers } from './providers';

export default function RootLayout({ children }: { children: React.ReactNode }) {
    return (
        <html lang="en">
            <body>
                <Providers>{children}</Providers>
            </body>
        </html>
    );
}
```

Without `LinkProvider`, Parlour's links fall back to a plain `<a>`. They still work, but you lose Next.js routing.

### Compose components

A page can stay a Server Component and still use any Parlour component:

```tsx
// app/page.tsx
import { Button, Column, Container, Main } from '@troychaplin/parlour-ui';

export default function Page() {
    return (
        <Main>
            <Container>
                <Column cols="2/3">
                    <Column.Content>
                        <h1>Welcome</h1>
                        <p>A page built from Parlour components.</p>
                    </Column.Content>
                    <Column.Content>
                        <Button text="Get started" href="/start" />
                    </Column.Content>
                </Column>
            </Container>
        </Main>
    );
}
```

## Pages Router

The Pages Router has no Server Components, so set everything up in `pages/_app.tsx`:

```tsx
// pages/_app.tsx
import type { AppProps } from 'next/app';
import Link from 'next/link';
import { LinkProvider } from '@troychaplin/parlour-ui';
import '@troychaplin/parlour-ui/styles.css';

export default function App({ Component, pageProps }: AppProps) {
    return (
        <LinkProvider component={Link}>
            <Component {...pageProps} />
        </LinkProvider>
    );
}
```
