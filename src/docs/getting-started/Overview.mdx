# Getting Started

How to install and use Parlour in your project.

## Pick your context

| If you're building…                                   | Read                                                                                                                                    |
| ----------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| A Next.js app or other modern React framework         | [Installation](?path=/docs/overview-getting-started-installation--docs) → [Next.js](?path=/docs/overview-getting-started-next-js--docs) |
| A WordPress block, block theme, or hybrid theme       | [WordPress](?path=/docs/overview-getting-started-wordpress--docs)                                                                       |
| Anything where accessibility matters (it always does) | [Accessibility](?path=/docs/overview-getting-started-accessibility--docs)                                                               |

## Quick start

```sh
pnpm add @troychaplin/parlour-ui
```

```tsx
import { Button } from '@troychaplin/parlour-ui';
import '@troychaplin/parlour-ui/styles.css';

<Button text="Save" />;
```

For the full install flow, see [Installation](?path=/docs/overview-getting-started-installation--docs).
