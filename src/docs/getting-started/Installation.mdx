# Installation

How to install `@troychaplin/parlour-ui` in a React project.

## 1. Install

```sh
pnpm add @troychaplin/parlour-ui
```

React and React DOM are peer dependencies — React 18 or 19.

## 2. Import styles

Once, near the top of your application:

```tsx
import '@troychaplin/parlour-ui/styles.css';
```

This is the bundled stylesheet: the design tokens, base element styles, layout classes, every component's CSS, and the `@font-face` rules for Inter Tight, Source Serif 4 and JetBrains Mono. The font files ship with the package, and your bundler picks them up from the stylesheet. The components don't import any CSS themselves, so this import is required.

## 3. Use components

```tsx
import { Button, Container, Main } from '@troychaplin/parlour-ui';

export function Page() {
    return (
        <Main>
            <Container>
                <h1>Hello, Parlour</h1>
                <Button text="Get started" href="/start" />
            </Container>
        </Main>
    );
}
```

If your app uses a client-side router, wrap it in [`LinkProvider`](?path=/docs/components-utilities-linkprovider--docs) so Parlour's links use your router's link component. For framework-specific setup, see [Next.js](?path=/docs/overview-getting-started-next-js--docs) or [WordPress](?path=/docs/overview-getting-started-wordpress--docs).

## Individual stylesheets (optional)

Each layer of the stylesheet, and each component's CSS, is also published on its own:

```tsx
import '@troychaplin/parlour-ui/tokens.css';
import '@troychaplin/parlour-ui/base-styles.css';
import '@troychaplin/parlour-ui/layout.css';
import '@troychaplin/parlour-ui/typography.css';
import '@troychaplin/parlour-ui/fonts.css';
import '@troychaplin/parlour-ui/Button.css';
```

These files leave out Parlour's global styles, such as the focus outline, the text selection color and the alignment widths, which only ship in `styles.css` and `hybrid-theme.css`. Use them where something else already provides that base, such as a WordPress block on a site whose theme loads Parlour. Component CSS reads the `--parlour--*` custom properties, so load `tokens.css` wherever you load a component's CSS.
