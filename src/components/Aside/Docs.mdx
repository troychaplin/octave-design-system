# Aside

A semantic `<aside>` wrapper for supplementary content — sidebars, related links, callout boxes, or any content complementary to the main article. Supports optional sticky positioning via the `isSticky` prop.

## When to use

Use `Aside` inside a `Column` layout alongside a main content area. The most common patterns are a right-hand sidebar (navigation, related content) or a left-hand sticky sidebar (table of contents, filters).

## Import

```tsx
import { Aside } from '@troychaplin/parlour-ui';
```

## Basic usage

```tsx
// Right sidebar
<Column cols="2/3">
  <Column.Content>
    <p>Main content...</p>
  </Column.Content>
  <Aside>
    <p>Related links...</p>
  </Aside>
</Column>

// Sticky left sidebar
<Column cols="1/3">
  <Aside isSticky topSpace={80}>
    <nav>Table of contents</nav>
  </Aside>
  <Column.Content>
    <p>Long-form content...</p>
  </Column.Content>
</Column>
```

## Sticky positioning

When `isSticky` is `true`, the component wraps children in `<div class="sticky" style={{ top: topSpace + 'px' }}>`, and Parlour's styles give that wrapper `position: sticky`.

The wrapper sticks within the `<aside>`, so it only moves when the aside is taller than its content. In a `Column`, the grid stretches the aside to the height of the row, so keep the sticky content shorter than the main column beside it — a table of contents or a short list of filters, not a second article. When the columns stack on small screens, the aside is only as tall as its content and scrolls with the page.

> **Note:** Parlour doesn't style the `parlour-prose` and `relative` classes on the `<aside>`. Styling for them must come from the consumer project.

## CSS classes

| Class           | Element       | Notes                                                     |
| --------------- | ------------- | --------------------------------------------------------- |
| `parlour-aside` | `<aside>`     | Always — scopes the sticky rule; no styles of its own     |
| `parlour-prose` | `<aside>`     | Always — prose typography hook, not yet styled internally |
| `relative`      | `<aside>`     | Always — expected to provide `position: relative`         |
| `sticky`        | Inner `<div>` | Only when `isSticky` is true — gets `position: sticky`    |

## Design tokens

None. The stylesheet's one rule sets `position: sticky`, and the `top` offset is a raw pixel value from the `topSpace` prop rather than a spacing token.

## Accessibility

- `<aside>` is a complementary landmark. Screen readers surface it as a navigable region distinct from the main content.
- The `landmark-complementary-is-top-level` axe rule is suppressed in the Storybook stories because `<aside>` is nested inside `<main>` for demo purposes. In production, this nesting is valid and the rule can be configured per project.
- Ensure the aside has a discernible label when multiple complementary landmarks appear on the same page — add `aria-label` or `aria-labelledby` via the `...rest` passthrough if needed.
