# Hero Header

The heading block for a page's [`Hero`](?path=/docs/components-content-hero--docs): an optional prefix line, a large title with an optional italic accent, and whatever you pass as children. Renders a `<header>` containing an `<h1>`, or the heading level set by `level`.

## When to use

- Lead the page from inside a `Hero`, in its `parlour-hero__content` column next to the hero's media.
- Add a stats row, an intro paragraph or actions below the title by passing them as children.
- Don't use it for the sections further down the page — [`SectionHeader`](?path=/docs/components-content-section-header--docs) is the smaller heading for those — or for the site-wide header, which is `SiteHeader`.

## Import

```tsx
import { HeroHeader } from '@troychaplin/parlour-ui';
```

## Basic usage

```tsx
// Title only — renders an <h1>
<HeroHeader title="Plugins, projects" />

// Prefix and italic accent
<HeroHeader
    prefix="Building for the open web."
    title="Plugins, projects"
    titleAccent="& open source contributions"
/>

// Stats row passed as children
<HeroHeader title="Plugins, projects">
    <ul className="parlour-hero-header__stats">
        <li>7 released plugins</li>
        <li>5 experimental projects</li>
    </ul>
</HeroHeader>

// Inside a Hero, next to a code sample
<Hero>
    <div className="parlour-hero__content">
        <HeroHeader title="Plugins, projects" titleAccent="& open source contributions" />
    </div>
    <div className="parlour-hero__code">
        <CodeBlock code={code} />
    </div>
</Hero>
```

## CSS classes

| Class                               | When applied                                                           |
| ----------------------------------- | ---------------------------------------------------------------------- |
| `parlour-hero-header`               | Always — base class                                                    |
| `parlour-hero-header__prefix`       | `prefix` is set — on the `<p>` above the title                         |
| `parlour-hero-header__title`        | `title` is set — on the heading                                        |
| `parlour-hero-header__title-accent` | `titleAccent` is set — on the `<span>` inside the heading              |
| `parlour-hero-header__stats`        | Never added by the component — put it on a `<ul>` you pass as children |

A `className` you pass is appended after `parlour-hero-header`. The stats row styles only apply to a `ul.parlour-hero-header__stats` inside the header, so the class has no effect elsewhere.

## Design tokens

| Token                                   | Used for                                        |
| --------------------------------------- | ----------------------------------------------- |
| `--parlour--font-size-4-x-large`        | Title font size                                 |
| `--parlour--font-weight-normal`         | Title font weight                               |
| `--parlour--color-neutral-900`          | Title color, outside dark and medium Containers |
| `--parlour--color-white`                | Title color inside dark and medium Containers   |
| `--parlour--font-family-source-serif-4` | Accent font family                              |
| `--parlour--font-weight-extra-light`    | Accent font weight                              |
| `--parlour--font-size-medium`           | Prefix font size                                |
| `--parlour--font-weight-light`          | Prefix and stats font weight                    |
| `--parlour--spacing-2-x-large`          | Space below the prefix; gap between stats       |
| `--parlour--font-size-small`            | Stats font size                                 |
| `--parlour--spacing-x-large`            | Space above the stats row                       |
| `--parlour--spacing-medium`             | Space between the stats divider and the items   |
| `--parlour--color-neutral-300`          | Stats divider color                             |

The title's `line-height` (`1.1`) and `letter-spacing` (`-2px`), and the stats divider's `1px` width, use raw values rather than design tokens.

## Accessibility

- `HeroHeader` renders a `<header>`. `Hero` renders a `<section>`, so it's a grouping element there rather than a second `banner` landmark next to the site header. If you use it outside a `Hero`, keep it inside [`Main`](?path=/docs/components-template-parts-main--docs) for the same reason.
- The title is the page's `<h1>` by default, so use one `HeroHeader` per page. Pass `level={2}` only when something else on the page is the main heading.
- `titleAccent` is part of the heading. A space separates it from `title`, so screen readers announce the whole phrase as one heading; the italic styling is visual only.
- The prefix is a paragraph before the heading, not part of it. Screen reader users who jump between headings skip it, so don't put information only there.
- A stats list is announced as a list with its item count. Write each item as a complete phrase ("7 released plugins"), not a bare number.
- The title is `--parlour--color-neutral-900` on light backgrounds and turns white inside dark and medium `Container`s at every heading level, `<h1>` included. The prefix and stats inherit the surrounding text color, so they follow the container too.
