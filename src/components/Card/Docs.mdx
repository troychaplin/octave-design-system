# Card

A surface for grouping related content: a `white`, `light`, `medium` or `dark` background with a matching text colour, an optional border, square or rounded corners, and padding. Renders a `<div>` by default, or the element set by `as`.

## When to use

- Present one item of a collection — a project, an article, a feature — usually inside a [`GridGroup`](?path=/docs/components-layout-grid-group--docs).
- Render it `as="article"` for content that stands on its own, or `as="li"` inside a `GridGroup` rendered `as="ul"`.
- For a ready-made design, use a design card such as [`ProjectCard`](?path=/docs/components-cards-project-card--docs), which is built on `Card`. Use `Card` directly for custom one-off content.
- Don't use it for page sections with full-width backgrounds — that's [`Container`](?path=/docs/components-layout-container--docs).

## Import

```tsx
import { Card } from '@troychaplin/parlour-ui';
```

## Basic usage

```tsx
// The defaults: a light background and border, square corners
<Card>…</Card>

// No border, rounded corners
<Card border={false} borderRadius="lg">…</Card>

// A dark card — the text turns white with it
<Card backgroundColor="dark" borderColor="dark">…</Card>

// Cards in a list
<GridGroup as="ul">
    <Card as="li">…</Card>
    <Card as="li">…</Card>
</GridGroup>

// The whole card as one link, named by its heading
<Card href="/work" linkProps={{ 'aria-labelledby': 'work-title' }}>
    <h3 id="work-title">Work</h3>
    <p>…</p>
</Card>
```

## Examples

### Default

The defaults match the project cards: a `light` background (`neutral-50`), a 1px `light` border (`neutral-300`), square corners and `large` padding on every side.

### Without a border

`border={false}` drops the border, leaving the background to separate the card from what's around it.

<Canvas of={CardStories.WithoutBorder} />

### Padding

`paddingInline` sets the left and right padding and `paddingBlock` the top and bottom. Each takes any step of the spacing scale, or `none`, and both default to `large`.

<Canvas of={CardStories.Padding} />

### Rounded

`borderRadius` takes any radius token — `sm`, `md`, `lg`, `xl` or `full` — or `none`, the default.

<Canvas of={CardStories.Rounded} />

### Colours

`backgroundColor` takes `white`, `light`, `medium` or `dark`, and the text colour follows it: black on `white` and `light`, white on `medium` and `dark`. `borderColor` takes the same four names.

<Canvas of={CardStories.Colors} />

### In a dark Container

The card keeps its own text colour, so a light card inside a dark `Container` stays readable. Headings inside it follow the card's text colour rather than the container's white heading style.

<Canvas of={CardStories.InDarkContainer} />

### With a link

Set `href` and the card wraps its children in a link that fills the card, so a click anywhere on it follows the link. The link comes from [`LinkProvider`](?path=/docs/components-utilities-linkprovider--docs), so it's your router's link component. The card hands its padding to the link, so `paddingInline` and `paddingBlock` still set the spacing. `linkProps` passes attributes to the link — `aria-labelledby`, `target`, `rel` — while the rest of the props stay on the card element. [`ProjectCard`](?path=/docs/components-cards-project-card--docs) uses this for its `href`.

## CSS classes

| Class                                 | When applied                                                                                             |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `parlour-card`                        | Always — base class                                                                                      |
| `parlour-card--bg-{name}`             | Always — the `backgroundColor` value, e.g. `parlour-card--bg-light` (default); also sets the text colour |
| `parlour-card--border`                | `border` is true (default) — a 1px solid border                                                          |
| `parlour-card--border-{name}`         | `border` is true — the `borderColor` value, e.g. `parlour-card--border-light` (default)                  |
| `parlour-card--radius-{size}`         | Always — the `borderRadius` value, e.g. `parlour-card--radius-none` (default)                            |
| `parlour-card--padding-inline-{step}` | Always — the `paddingInline` value, e.g. `parlour-card--padding-inline-large` (default)                  |
| `parlour-card--padding-block-{step}`  | Always — the `paddingBlock` value, e.g. `parlour-card--padding-block-large` (default)                    |
| `parlour-card--linked`                | `href` is set — padding moves to the link, and the border darkens on hover                               |
| `parlour-card__link`                  | `href` is set — on the link wrapping the children; fills the card and takes its padding                  |

The padding modifiers set `--parlour-card-padding-inline` and `--parlour-card-padding-block`, which the card uses for its padding. On a `parlour-card--linked` card, the card's padding drops to `0` and the link uses those properties instead.

The first child's top margin and the last child's bottom margin are removed, so the padding looks even — inside a `parlour-card__link` too. Headings inside the card inherit its text colour. A `className` you pass is appended after these classes.

## Design tokens

| Token                             | Used for                                                                      |
| --------------------------------- | ----------------------------------------------------------------------------- |
| `--parlour--color-white`          | `white` background; text on `medium` and `dark` cards; `white` border         |
| `--parlour--color-neutral-50`     | `light` background (default)                                                  |
| `--parlour--color-neutral-900`    | `medium` background; `dark` border                                            |
| `--parlour--color-neutral-950`    | `dark` background                                                             |
| `--parlour--color-black`          | Text on `white` and `light` cards                                             |
| `--parlour--color-neutral-300`    | `light` border (default)                                                      |
| `--parlour--color-neutral-500`    | `medium` border; border of a linked card while hovered                        |
| `--parlour--spacing-*`            | `paddingInline` and `paddingBlock` — any step of the spacing scale, or `none` |
| `--parlour--radius-*`             | `borderRadius` — `sm`, `md`, `lg`, `xl` or `full`                             |
| `--parlour--color-accent-primary` | Focus outline on the link                                                     |
| `--parlour--transition-fast`      | Border colour change on a linked card                                         |

A `light` card (`neutral-50`) is a step lighter than a `light` [`Container`](?path=/docs/components-layout-container--docs) (`neutral-200`), so it stands out on a light section. The border's `1px` width and the link's `2px` focus outline are raw values rather than design tokens.

## Accessibility

- The default `<div>` adds no semantics. Use `as="article"` for a self-contained item, and `as="li"` when the card is one of a list.
- The background sets the card's own text colour, so its text stays readable whichever section it sits in, and headings inside it follow that colour too.
- Every background passes WCAG AA with its text colour: black on `white` is about 18:1 and on `light` about 16:1; white on `medium` is about 11:1 and on `dark` about 16:1.
- A full-card link is announced with all of its text unless you name it. Pass `linkProps={{ 'aria-labelledby': … }}` pointing at the card's heading so screen readers announce just the title, and keep other links and buttons out of the card — interactive elements can't be nested inside a link.
- `Card` is a client component (`'use client'`) because it reads `LinkProvider`. Server components can still render it and pass it server-rendered children.
- The link resets Main's bold, underlined link style so the card's text looks the same linked or not. Its focus outline is drawn around the whole card.
- The border is decorative — it isn't needed to understand the content — so it isn't held to a contrast ratio.
