# Button

A flexible action trigger that renders a native `<button>` element. Supports five color variants (with an optional outline treatment), size and width modifiers, and a disabled state.

## When to use

Use `Button` when you need an interactive control that triggers an in-page action — submitting a form, opening a dialog, or kicking off a process. For links that navigate to a URL, prefer a semantic `<a>` element or your framework's `Link` component instead. When placing two or more buttons side by side, wrap them in a [`ButtonGroup`](?path=/docs/components-elements-button-group--docs) rather than managing spacing manually.

## Import

```tsx
import { Button } from '@troychaplin/octave-design-system';
```

## Basic usage

```tsx
<Button title="Get started" color="primary" />
<Button title="Download" color="dark" />
<Button title="Cancel" color="primary" isOutline />
```

## CSS classes

| Class                      | When applied                               |
| -------------------------- | ------------------------------------------ |
| `octave-button`            | Always — base class                        |
| `octave-button--primary`   | `color="primary"` (default)                |
| `octave-button--secondary` | `color="secondary"`                        |
| `octave-button--neutral`   | `color="neutral"`                          |
| `octave-button--dark`      | `color="dark"`                             |
| `octave-button--light`     | `color="light"`                            |
| `octave-button--disabled`  | `isDisabled={true}`                        |
| `octave-button--outline`   | `isOutline={true}` (ignored when disabled) |
| `octave-button--small`     | `isSmall={true}`                           |
| `octave-button--full`      | `isFull={true}`                            |

A top margin (`2rem` mobile, `2.5rem` desktop) is automatically applied when a `Button` or `ButtonGroup` directly follows a `Column` or `StackedList` element — no extra spacing class needed.

## Design tokens

These `--octave--*` custom properties drive the Button's appearance. Overriding them at a higher scope will change every Button on the page.

| Token                               | Used for                                                                                       |
| ----------------------------------- | ---------------------------------------------------------------------------------------------- |
| `--octave--spacing-x-small`         | Vertical padding on mobile                                                                     |
| `--octave--spacing-medium`          | Horizontal padding on mobile                                                                   |
| `--octave--spacing-small`           | Vertical padding above the tablet breakpoint                                                   |
| `--octave--spacing-large`           | Horizontal padding above the tablet breakpoint                                                 |
| `--octave--font-family-inter-tight` | Font family                                                                                    |
| `--octave--font-size-small`         | Font size on mobile and when `isSmall`                                                         |
| `--octave--font-size-medium`        | Font size above the tablet breakpoint                                                          |
| `--octave--font-weight-medium`      | Font weight                                                                                    |
| `--octave--line-height-tight`       | Line height                                                                                    |
| `--octave--radius-md`               | Border radius                                                                                  |
| `--octave--color-accent-primary`    | `primary` background; hover background for `neutral`, `dark` and `light`                       |
| `--octave--color-accent-secondary`  | `secondary` background                                                                         |
| `--octave--color-neutral-800`       | `dark` background; `neutral` and disabled text; hover background for `primary` and `secondary` |
| `--octave--color-neutral-100`       | `neutral` background                                                                           |
| `--octave--color-neutral-300`       | Disabled background                                                                            |
| `--octave--color-white`             | `light` background; text on filled variants; outline background                                |
| `--octave--color-black`             | `light` text                                                                                   |

The `gap`, the `isSmall` padding and the top margin after a `Column` or `StackedList` use raw values rather than design tokens.

## Accessibility

- `Button` renders a native `<button>` element — keyboard focus, `Enter`/`Space` activation, and screen reader announcement are built in.
- **Buttons without a `title` require `ariaLabel`.** It gives the button its accessible name, and the TypeScript union type enforces this at compile time.
- The native `disabled` attribute prevents the button from receiving focus or firing events. Do not use CSS-only disabled styling, as it leaves the button keyboard-reachable.
- Avoid using `Button` for navigation — screen readers expose `role="button"` to users, who expect it to perform an action rather than navigate.
