# Badge Group

A flex container that wraps one or more `Badge` components into a horizontal, wrapping row. Set `isAbsolute` to position the group over an image or other content.

## When to use

Use `BadgeGroup` whenever you need more than one badge to appear together — as a tag list below a heading, or, with `isAbsolute`, as an overlay cluster on an image. For a single badge, `BadgeGroup` is optional but harmless.

## Import

```tsx
import { Badge } from '@troychaplin/octave-design-system';
import { BadgeGroup } from '@troychaplin/octave-design-system';
```

## Basic usage

```tsx
// Inline tag list
<BadgeGroup>
    <Badge text="Research" color="neutral" />
    <Badge text="Open Access" color="success" />
</BadgeGroup>
```

## CSS classes

| Class                | When applied                                    |
| -------------------- | ----------------------------------------------- |
| `octave-badge-group` | Always — base class on the `BadgeGroup` element |

`isAbsolute` applies `position: absolute` and the `top` / `right` / `bottom` / `left` pixel offsets as inline styles rather than classes; `top` and `left` default to `0`.

## Design tokens

| Token                         | Used for                        |
| ----------------------------- | ------------------------------- |
| `--octave--spacing-2-x-small` | Gap between badges in the group |

## Accessibility

- `BadgeGroup` renders a plain `<div>` with no ARIA role — it is a visual layout wrapper only.
- Individual `Badge` components within the group retain their own semantics (inline text or link).
- When overlaying with `isAbsolute`, keep the badges in a logical reading order relative to the surrounding content in the DOM.
